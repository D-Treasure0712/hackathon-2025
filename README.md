# Configuration

# Docker環境の利用
Docker環境を立ち上げるコマンド

```
docker compose up --build
```

予防措置（将棋実行ファイル起動しない場合）
```
cd backend
go run .
```

Frontend確認用URL：<http://localhost:3000>

Backend確認用URL：<http://localhost:8080>
